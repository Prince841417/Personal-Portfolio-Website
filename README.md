2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use VS Code Live Server if installed.
4. Test all navigation links and resize the browser to check mobile layout.

## Project description 
This is a responsive personal portfolio website created with HTML5 and CSS3. It includes Home, About, Skills, Projects, Contact, and Footer sections, with navigation anchors and project cards. CSS Grid, Flexbox, hover/focus states, and media queries help the layout adapt to desktop and mobile screens. The website is a static frontend demonstration; it does not use JavaScript, a backend, or a database.

## Compliance
The core website uses HTML and CSS only. The mobile navigation uses a CSS checkbox/label pattern, not JavaScript. External Google Fonts are optional; the page has fallback fonts if the font service is unavailable.
